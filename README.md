# 協同準則 AI 學習系統 V5.6

## 本版整合功能

### 模擬考百分制
- 滿分固定 100 分。
- 各題依錯字、漏字、多字，每字扣 0.5 分。
- 累計扣分最高 100 分，最低成績為 0 分。
- 若前面題目累計扣分已達 100 分，後續題目不再扣分。
- 後續題目仍顯示錯字、漏字、多字、逐字標示與標準答案。
- 扣分已達上限時，該題顯示「本題僅顯示需修正部分」。
- 模擬考完成 20 題或 100 題後，才公布總分、總扣分與合格結果。

### 錯題庫分析
- 顯示每題累計錯誤次數。
- 統計常漏／常錯字。
- 統計常多寫／誤寫字。
- 顯示最近一次逐字錯誤標示。
- 錯題依錯誤次數排序。
- 可重做單題及移除錯題紀錄。

### 其他保留功能
- Fisher–Yates 真正隨機洗牌，同一場不重複抽題。
- 練習區段、自行選題、收藏、搜尋、學習統計與方塊消除。
