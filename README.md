# 協同準則 AI 學習系統 V5.4 百分制扣分上限版

本版修正模擬考計分：

- 模擬考滿分固定為 100 分。
- 所有題目的扣分由 100 分向下累計。
- 累計扣分最高為 100 分，總分最低為 0 分。
- 累計扣分已達 100 分後，後續題目不再扣分，只顯示錯字、漏字、多字與標準答案。
- 單題扣分若超過剩餘可扣分數，只扣到總扣分 100 分為止。
- 20 題或 100 題全部完成後，才顯示最終總分、總扣分與合格結果。
- 保留 Fisher–Yates 隨機洗牌，同一場測驗不重複抽題。

將 `index.html` 與 `README.md` 覆蓋上傳至 GitHub Pages 專案即可。
